# تالين — زاحف 1688 (إضافة Chrome)
تعمل من متصفح الموظف المسجّل في 1688 (عنوان سكني، لا يحجبه 1688) وتنفذ المهام المعرّفة في `/admin/crawler`:
- **بحث/رابط**: تفتح صفحات النتائج في تبويب خلفي، تستخرج المنتجات، ترسلها إلى `/api/import`، ثم تفتح صفحة كل منتج جديد لجلب الصور والمقاسات والألوان.
- **فحص مخزون**: تجلب قائمة المنتجات الأهم من `/api/import/queue` وتفحص توفرها وسعرها وترسل `/api/import/check`.
- تفحص المهام كل 15 دقيقة (chrome.alarms)، وتتوقف ساعتين عند كابتشا مع إشعار.
التثبيت: chrome://extensions → وضع المطوّر → تحميل غير مضغوط → هذا المجلد → أيقونة الإضافة → العنوان والرمز → حفظ.
