# مقارنة صفحات شي إن (SHEIN) بصفحات تالين — الإصدار 2

المصدر: بنية موقع/تطبيق شي إن للزبون كما هو منشور علنًا (الحساب، الطلبات، الإرجاع، النقاط، الكوبونات، التقييمات، الدعم). لوحة إدارة شي إن الداخلية **غير منشورة**؛ لذلك بُنيت لوحة تالين على ما تفرضه صفحات الزبون من عمليات، وعلى معايير مراكز البائعين المعروفة (SHEIN Seller Center / Shopify Admin)، وعلى عمليات تالين الفعلية (شراء من 1688 وشحن عبر شريك).

## واجهة الزبونة

| # | صفحة شي إن | صفحة تالين | الحالة |
|---|---|---|---|
| 1 | الرئيسية (بانر، أقسام، فلاش سيل، الأكثر رواجًا، وصل حديثًا، شاهدتِ مؤخرًا) | `/` | ✅ مكتملة |
| 2 | قائمة القسم مع فلاتر (سعر، مقاس، لون) وترتيب (رواج، أحدث، تقييم، سعر) | `/c/:slug` | ✅ |
| 3 | البحث | `/search` | ✅ |
| 4 | صفحة المنتج: معرض، ألوان/مقاسات، دليل مقاسات، رأي الزبونات في المقاس، تقييمات، مقترحات | `/p/:slug` | ✅ (كانت بلا تقييمات) |
| 5 | السلة + كوبون | `/cart` | ✅ (أُضيف الكوبون) |
| 6 | إتمام الطلب: دفتر عناوين، كوبون، نقاط، وسائل دفع فورية | `/checkout` | ✅ (كان عنوانًا واحدًا وبلا خصومات) |
| 7 | صفحة الدفع المستضافة (بطاقة/محفظة) | ماي باي `/pay/start` → صفحة MyPay → `/pay/return` | ✅ جديد |
| 8 | تأكيد الطلب + تتبع مراحله | `/orders/:code` | ✅ |
| 9 | إلغاء الطلب قبل الدفع | زر في صفحة الطلب | ✅ جديد |
| 10 | حسابي: نظرة عامة بمراحل الطلبات | `/account` | ✅ جديد |
| 11 | طلباتي مع فلاتر المراحل | `/account/orders` | ✅ جديد |
| 12 | الإرجاع/الاسترجاع (Return & Refund Record) | `/account/tickets` (إرجاع/مشكلة/سؤال/إلغاء) | ✅ جديد — بسياسة تالين (تعويض بدل إعادة للصين) |
| 13 | كتابة تقييم بنقاط مكافأة (+صورة +مقاس) | `/account/reviews` | ✅ جديد |
| 14 | كوبوناتي | `/account/coupons` | ✅ جديد |
| 15 | نقاطي (كسب، استخدام حتى 50%) | `/account/points` | ✅ جديد |
| 16 | دفتر العناوين | `/account/addresses` | ✅ جديد |
| 17 | المفضلة | `/wishlist` | ✅ |
| 18 | الإشعارات/الرسائل | `/account/notifications` | ✅ جديد |
| 19 | الملف الشخصي وكلمة المرور | `/account/profile` | ✅ جديد |
| 20 | الدخول/التسجيل (بالهاتف) | `/login` `/register` | ✅ |
| 21 | مركز المساعدة: أسئلة شائعة، شحن، إرجاع، شروط، خصوصية، تواصل | `/pages/faq|shipping|returns|terms|privacy|contact` | ✅ (أُضيفت 3 صفحات) |
| 22 | المحفظة (Wallet) للاسترجاع النقدي | — | ⏳ الاسترجاع حاليًا بالنقاط أو يدويًا عبر المالية |
| 23 | بطاقات الهدايا | — | ⏳ غير مطلوبة الآن |
| 24 | دردشة مباشرة | تذاكر + واتساب | ⏳ بديل مناسب للسوق الليبي |
| 25 | تسجيل الدخول الاجتماعي / استعادة كلمة المرور بالبريد | — | ⏳ الهاتف هو المعرف؛ الاستعادة عبر الدعم |

الإجمالي: 21 من 25 وظيفة مطابقة وتعمل، و4 مؤجلة عن قصد.

## لوحة الإدارة والموظفين

| الوظيفة | صفحة تالين | الصلاحية |
|---|---|---|
| نظرة عامة (11 مؤشرًا + اختصارات) | `/admin` | dashboard |
| الطلبات وتفاصيلها وتأكيد الدفع اليدوي وتغيير الحالة | `/admin/orders` | orders.view / orders.manage |
| المدفوعات وإعدادات ماي باي وسجل الويبهوك | `/admin/payments` | payments.view / payments.manage |
| الزبائن وملف الزبونة (نقاط، تعطيل) | `/admin/customers` | customers.view / customers.manage |
| التذاكر والإرجاع (رد، تعيين، قرار: نقاط/استرجاع/بديل/إلغاء) | `/admin/tickets` | tickets.manage |
| مراجعة التقييمات (نشر/رفض → يحدّث تقييم المنتج) | `/admin/reviews` | reviews.manage |
| الكوبونات (نسبة/ثابت/توصيل مجاني، حدود، انتهاء) | `/admin/coupons` | coupons.manage |
| الكتالوج: استيراد 1688، منتجات، أقسام، مخزون، API | `/admin/import` … | catalog.manage |
| التسعير وسعر الصرف | `/admin/pricing` | pricing.manage |
| شركاء الشحن | `/admin/partners` | partners.manage |
| الموظفون والأدوار ومصفوفة الصلاحيات | `/admin/staff` | staff.manage |
| التقارير (يومي، الأكثر مبيعًا، مدن، طرق دفع، حالات) | `/admin/reports` | reports.view |
| سجل النشاط | `/admin/activity` | logs.view |
| لوحة شريك الشحن (شراء، مخزن، شحنات، تسليم) | `/partner` | دور partner |

### الأدوار
| الدور | يرى/يفعل |
|---|---|
| المالك | كل شيء بما فيه الموظفون |
| مدير عام | كل شيء عدا إدارة الموظفين |
| عمليات | الطلبات، الشركاء، التذاكر، التقارير |
| دعم الزبائن | التذاكر، الزبائن، التقييمات، عرض الطلبات |
| مالية | المدفوعات، التسعير، الكوبونات، التقارير، السجل |
| الكتالوج | المنتجات، الاستيراد، الأقسام، المخزون، التقييمات |

أي صفحة خارج صلاحية الدور تعيد 403 مع توضيح، والقائمة الجانبية لا تعرض إلا المسموح.
