# تشغيل دلال على كمبيوترك

مُجرَّب على نسخة نظيفة من المستودع، والأوامر نفسها تعمل على **ويندوز** و**ماك** و**لينكس** (لا فرق بينها).

## 1. المتطلبات (مرة واحدة)
- **Node.js 22** أو أحدث: <https://nodejs.org> (اختر LTS).
- **Git**: <https://git-scm.com/downloads>.
- **Google Chrome** (لإضافة الزاحف ولاختبارات الشاشة).

تأكد من التثبيت:
```
node -v
git --version
```

## 2. أربعة أوامر فقط
```
git clone https://github.com/tsallabi/Dlal.git
cd Dlal
npm ci
npm run setup
npm run dev
```
ثم افتح <http://localhost:8787>.

`npm run setup` يفعل شيئين تلقائيًا: ينشئ ملف الأسرار المحلي `.dev.vars`، ويطبّق ترحيلات قاعدة البيانات المحلية بلا أي سؤال تأكيد.

> **لا تستخدم** `cp .dev.vars.example .dev.vars` على ويندوز، فأمر `cp` غير موجود في موجه الأوامر. `npm run setup` يغني عنه على كل الأنظمة.

> إن شغّلت `npx wrangler d1 migrations apply ...` يدويًا، سيسألك **?Your database may not be available … continue**. اضغط **y** ثم Enter. الإجابة بـ n تُلغي إنشاء الجداول ولن يعمل الموقع.

## 3. حسابات النسخة المحلية
للتجربة المحلية فقط، ولا علاقة لها بالموقع الحي:

| الدور | الهاتف | كلمة المرور |
|---|---|---|
| المالك | 0910000000 | admin123 |
| شريك الصين (شاهين) | 0920000000 | partner123 |
| زبونة | 0930000000 | customer123 |

قاعدة البيانات المحلية منفصلة تمامًا عن الموقع الحي وفيها بيانات تجريبية، فجرّب فيها بحرية.

**ملاحظة**: `wrangler.local.toml` بلا ربط Workers AI عمدًا لأن الربط يحتاج اتصالًا بحساب Cloudflare. لذلك ترجمة العناوين بالذكاء الاصطناعي لا تعمل محليًا (القاموس يعمل)، وتعمل كاملة على الموقع الحي.

## 4. بقية الأوامر
```
npm run e2e          # اختبار الشاشة الشامل (الخادم المحلي يجب أن يكون شغّالًا)
npm run typecheck    # فحص الأنواع
npm run migrate:local
```
قبل أول تشغيل لـ `npm run e2e` نفّذ مرة واحدة: `npx playwright install chromium`.
يجب أن ينتهي الاختبار بـ «كل الفحوصات نجحت ✓» قبل أي دفع إلى `main`.

## 5. النشر
لا تنشر يدويًا. أي دفع إلى `main` ينشر تلقائيًا إلى Cloudflare ثم يشغّل فحص الموقع الحي.
```
git add -A
git commit -m "وصف التغيير"
git push
```
تابع النتيجة على <https://github.com/tsallabi/Dlal/actions>.

## 6. إضافة الزاحف على نفس الجهاز
نزّل <https://dlal.tsallabi.workers.dev/dlal-extension.zip>، فكّ الضغط في مجلد ثابت، ثم `chrome://extensions` ← فعّل «وضع المطوّر» ← «تحميل غير مضغوط» ← اختر المجلد الذي فيه `manifest.json`. من أيقونة الإضافة أدخل عنوان الموقع والرمز (`IMPORT_TOKEN` معروض في `/admin/crawler` بعد الدخول كمالك). سجّل الدخول في 1688 في نفس المتصفح واتركه مفتوحًا.

## 7. متابعة العمل مع كلود من نفس الجهاز
انظر `docs/CLAUDE-CODE-WINDOWS.md`.
